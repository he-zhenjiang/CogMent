## What is CogMent

CogMent is a **reusable, verifiable, and iterative** thinking methodology framework—not a collection of scattered tips, but a **cognitive infrastructure**:

- **104 Thinking Techniques**: Covering the full spectrum from divergence to convergence, from single-cause to systems thinking, from cognition to verification
- **6 Structural Forms**: Point→Linear→Planar→Ladder→Network→Spherical, with problem types mapped to thinking forms
- **Dual Locator**: 30-second matching of "which thinking tool fits this problem"
- **Boundary Self-Check**: Verify "is this problem solvable by these tools" before use

## Design Principles

1. **Verifiable** — Every technique includes a "falsification checklist"; outputs withstand scrutiny
2. **Reusable** — Techniques classified by structural form; same problem type auto-reuses
3. **Iterative** — Boundary check + post-task metacognitive reflection prevent misuse
4. **Human-AI Synergy** — Locator and checklist are "human decision entry points"; AI executes and verifies
