## 这是什么

CogMent是一套**可复用、可验证、可迭代**的思维方法论框架，不是零散的技巧集合，而是一套**认知基础设施**：

- **104种思维技法**：覆盖从发散到收敛、从单因到系统、从认知到验证的全谱系
- **6层结构形态**：点型→线性→面型→梯型→网型→球型，问题类型与思维形态一一对应
- **双重定位器**：30秒快速匹配"当前问题该用哪种思维工具"
- **边界自检**：使用技法前先确认"这个问题是否属于技法可解范围"

## 核心设计原则

1. **可验证** —— 每个技法附带"证伪检查清单"，输出不怕质疑
2. **可复用** —— 技法按"结构形态"分类，同类问题自动复用
3. **可迭代** —— 边界自检 + 任务完成后元认知自省，防止工具误用
4. **人机协同** —— 定位器和自检清单是"人的决策入口"，AI负责执行和验证
